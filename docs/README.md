# Documentation

The documentation is divided into four roles:

- `derivations/`: original handwritten analytical work.
- `assets/original_comparisons/`: byte-identical copies of the eight original
  analytical-model versus PLECS comparison figures displayed in the READMEs.
- `derivation_status.md`: completion and traceability matrix.
- `methodology.md`: concise engineering workflow and notation.
- `validation_report.md`: numerical evidence, assumptions, and provenance.
- `simulink_model.md`: role and dependency notes for the original system model.
- `licensing.md`: practical license choices before public release.
- `repository_structure.md`: directory tree and ownership of each artifact class.
- `source/`: retained source document from the original working folder.

The handwritten PDFs are intentionally preserved as source evidence. Future
updates should add typed equations and stable equation identifiers rather than
silently replacing the originals.
