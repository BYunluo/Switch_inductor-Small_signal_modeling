# Handwritten Derivations

These PDFs preserve the original engineering derivation trail. They are
ordered by the intended modeling workflow:

1. [`01_large_signal_model.pdf`](01_large_signal_model.pdf) — switching-state
   and large-signal model notes (5 pages).
2. [`02_averaged_model.pdf`](02_averaged_model.pdf) — averaged model notes
   (2 pages).
3. [`03_state_space_equations.pdf`](03_state_space_equations.pdf) — state-space
   equations (7 pages).
4. [`04_transfer_functions.pdf`](04_transfer_functions.pdf) — transfer-function
   notes (2 pages).

The handwritten set is intentionally presented as work in progress. The
executable Python equations cover all eight validation cases, while the PDFs
do not yet provide a one-to-one derivation for every implemented expression.
See [`../derivation_status.md`](../derivation_status.md) for the tracking plan.
