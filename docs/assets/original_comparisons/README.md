# Original Comparison Figures

These eight PNG files are byte-identical copies of the combined magnitude and
phase comparison plots in the original `Small Signal Validation` work folders.
They are retained as source evidence and displayed in both repository READMEs.

The reproducible figures generated from the current equation modules and raw
PLECS CSV exports remain in [`../../../results/figures/`](../../../results/figures/).
In particular, the original `D2 → IL1, D2 > D1` plot predates the latest saved
equation source; see [`../../validation_report.md`](../../validation_report.md)
for the recorded provenance and current numerical result.
