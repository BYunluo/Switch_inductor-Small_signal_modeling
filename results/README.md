# Results

- `figures/`: eight combined magnitude-and-phase comparisons regenerated from
  the current Python equation modules and raw PLECS exports.
- `tables/`: point-by-point analytical and PLECS values with errors.
- `validation_summary.csv`: one-row-per-case maximum/RMS error summary.
- `generated/`: local rerun output; ignored by Git.

The checked-in results are evidence for the current equation-source version.
Changing an equation requires regenerating the associated table and figure and
reviewing the summary metrics.
